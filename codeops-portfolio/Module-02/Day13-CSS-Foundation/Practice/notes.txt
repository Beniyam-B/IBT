Cascade & Inheritance

cascade resolves conflicts in order
cascading is when several rules target the same element what decides which rule is applied?
-it is decided by the importance of the rules
-the more important the rule the higher it is in the cascade
-then its decided on specifity
-specifity is the number of selectors in the rule
-the more selectors the higher the specifity
-and the last one that would affect them is the last one in the cascade
-if there is no conflict then the last one is applied
-inheretance is when the same property is applied to different elements
-eg:h1 {color:red} and h2 {color:red} then the color will be red for h1 and h2 elements
using inheritance we can use the same property for different elements
-eg: h2{inherit} will make the color red for h2 elements insted of rewriting its

first we have the origin  eg:the origin is : h1 {}
then we have the speficities eg:the speficities is : h1.price {}
then we have the inline styles eg:the inline styles is : h1.price {color:red;}
then we have the internal styles eg:the internal styles is : h1 {color:red;}
then we have the external styles eg:the external styles is : @import url(style.css);

inheritance is the process of passing down the cascade
eg:h1 will inherit the cascade from h1.price
then source order eg:the source order is : h1.price {color:red;} then h1 {color:red;}

selector specificity
the more specific the selector the higher the specifity

h1.price will have the second highest specifity
h1.price.active will have the third highest specifity
which means that h1.price.active will have the highest specifity and will affect the exact element that has the class price and the id nav



The Box Model
every element in a browser renders in a rectangular box that has four layers 
content,padding,border,margin

content-is the content of the element

padding-is the space between the border and the content

border-is the space between the content and the margin

margin-is the space between the border and the edge of the browser or other elements

Box-sizing --is a property that is used to change the box model of an element

by default the content box width is sets only the content box padding and border are added on top.
so when you try to change the padding and border of an element the content box width will not change
so to change the content box width you have to use box-sizing property
eg:{box-sizing:border-box;} this will change the content box width

dissplay- how an element is displayed inside a box:

block , inline ,inline-block,list-item,table,inline-table

block is the most common display type it behaves like a paragraph, new line, fullwidth eg:div,p,h1,section

inline is the display type that behaves like a line eg:span,a,b,i,strong,em

inline-block is the display type that behaves like a block but in the same line eg:img,input,button

list-item is the display type that behaves like a list item eg:li

table is the display type that behaves like a table eg:table

inline-table is the display type that behaves like a table but in the same line eg:table

spacing shorthand property
padding and margin accept shorthand property they run clockwise top,right,bottom,left eg:margin:10px 20px; is the same as margin:10px 20px 10px 20px;

hexadecimal notation
hexadecimal notation is used to write the color codes
the first two digits are for the red color
the third two digits are for the green color
the forth two digits are for the blue color
the fifth two digits are for the alpha channel
eg:#f00 is the same as #ff0000

rgb notation
rgb notation is used to write the color codes
the first three digits are for the red color
the second three digits are for the green color
the third three digits are for the blue color
eg:rgb(255,0,0) is the same as #ff0000

rgba notation
rgba notation is used to write the color codes
the first three digits are for the red color
the second three digits are for the green color
the third three digits are for the blue color
the forth three digits are for the alpha channel
eg:rgba(255,0,0,0.5) is the same as #ff000080

hsl notation
hsl notation is used to write the color codes
the first three digits are for the hue
the second three digits are for the saturation
the third three digits are for the lightness
eg:hsl(120,100%,50%) is the same as #ff8000

hsla notation
hsla notation is used to write the color codes
the first three digits are for the hue  
the second three digits are for the saturation
the third three digits are for the lightness
the forth three digits are for the alpha channel
eg:hsla(120,100%,50%,0.5) is the same as #ff800080
